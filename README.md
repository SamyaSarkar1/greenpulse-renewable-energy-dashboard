# 🌱 GreenPulse – Renewable Energy Intelligence Dashboard

**A responsive dashboard for monitoring renewable energy generation, comparing actual vs forecast power, and analysing plant performance.**

GreenPulse is a frontend-based renewable energy analytics dashboard designed to visualize wind and solar power generation, monitor forecast deviations, and provide operational insights through interactive charts and KPIs.

## 🚀 Live Demo

[View GreenPulse Dashboard](https://greenpulse-renewable-energy-dashboard.netlify.app/)

*Replace this URL with your actual Netlify deployment link after publishing.*

## ✨ Features

- **Renewable Energy Overview:** Monitor total actual generation and forecast generation.
- **Actual vs Forecast Analysis:** Compare scheduled/forecast power with actual generation.
- **Interactive Charts:** Visualize generation trends using Chart.js.
- **Wind & Solar Analysis:** View generation contribution from different renewable sources.
- **Plant Performance:** Compare the performance of individual wind and solar plants.
- **Forecast Deviation:** Analyse differences between actual and forecast generation.
- **DSM Deviation Calculator:** Estimate deviation percentage and indicative deviation charges.
- **Interactive Filters:** Filter dashboard data by source, plant, and time period.
- **CSV Export:** Export plant performance data.
- **Responsive Design:** Access the dashboard on desktop, tablet, and mobile devices.

## 💻 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/SamyaSarkar1/greenpulse-renewable-energy-dashboard.git
```

2. Open the project folder:

```bash
cd greenpulse-renewable-energy-dashboard
```

3. Open `index.html` in your browser.

No backend or database setup is required for the current frontend demo.
